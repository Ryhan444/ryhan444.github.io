Craft

Upgrade-safe code, production-ready

I write Odoo the way core developers do — so modules survive upgrades, pass review and don't surprise anyone in production.

  • Inherit, never copyClean _inherit & XPath extensions, always calling super().
  • Recordset thinkingBatch operations, complete dependencies, no N+1 queries.
  • Secure by defaultAccess rights, record rules and multi-company checks from day one.
  • Branch → staging → productionEvery change tested on Odoo.sh before it reaches users.
